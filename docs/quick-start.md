# Quick Start

OASIS helps people review proposed security fixes for open source software. You do not need to own a project, write code, or create a patch to take part.

## What you need

- A GitHub account to sign in and participate.
- An OWASP Slack account is optional. Slack is one place to ask questions and join community discussions.

## Join Team OASIS

Use **Join Team OASIS** on the home page and complete the registration form. Then sign in with your GitHub account.

## Find a candidate fix

1. Open [Candidate Fixes](/workspace/fixes).
2. Choose a candidate from your queue, use the project filters, or browse all candidates.
3. Start with a project or finding you understand. You can return to another candidate at any time.

## Review the change

Read the candidate's Summary and Details, inspect its Diff, and review the Comments. Open the pull request on GitHub when you need more code or project context.

Ask two questions:

- Is the reported problem supported by the available evidence?
- Does the proposed change address it without creating an obvious new problem?

## Record a decision when you have enough support

Choose Accept, Modify, Reject, or Duplicate when the evidence supports that decision. The current form may ask for comments and, depending on the decision, confidence, a recommended action, or other context. Keep your explanation concise and tied to what you reviewed. See the [Reviewer Guide](/reviewer-guide) for more detail on the decisions and review questions.

If you are unsure, do not vote just to complete the review. Read the discussion, ask a question, or choose another candidate.

## What your validation means

An OASIS validation is community input for the candidate fix. It is not maintainer approval and does not merge code. Project maintainers make their own decisions about changes proposed to their repositories.
