# Workspace UI kit
Canonical source: **OASIS Workspace v2** (this is a frozen copy). Open `Workspace.dc.html` directly; `index.html` wraps it for the Design System tab.

Screens: My queue (home) · Candidate fixes (Split / Table / Focus layouts; Summary · Details · Diff · Comments tabs) · Projects · Validators · Maintainers · Preferences · Sync status.
Interactions: ↑/↓ move through the fix list; A/M/R/D choose a decision; ⌘/Ctrl+Enter submits; Esc clears the decision. Search accepts `14`, `#14`, `react 14`, `react#14`.
Preferences persist to localStorage key `oasis-ws-prefs-v2`.
