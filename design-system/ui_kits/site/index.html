How it works

From known CVE to merged patch.

Fix automation proposes a candidate fix. Validators score it. Trusted fixes go upstream.

01

Candidate fix

Fix automation opens a candidate fix for a known vulnerability.

02

Validation

Validators review the diff and vote Accept, Modify, Reject, or Duplicate.

03

Upstream submission

Trusted fixes are submitted to the maintainer as a pull request.
