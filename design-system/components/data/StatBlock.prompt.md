StatBlock — small set of personal/summary numbers. "stack" on gradient banners; "row" (1px-gap grid) on paper.
```jsx
<StatBlock tone="dark" direction="stack" items={[{label:'Your votes',value:3},{label:'Reputation',value:48.6},{label:'90-day rank',value:'#7'}]}/>
```
Max 4 stats. No decorative numbers.
